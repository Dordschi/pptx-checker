# 📊 Проверка презентации .pptx перед уроком

Программа на Python проверяет учебную презентацию PowerPoint по **9 параметрам** и выдаёт понятный учителю отчёт (в сантиметрах, с фрагментами текста и уровнем критичности) — **до того**, как файл откроют на проекторе в классе.

> Учебный проект для проектной деятельности, 10 класс.

## Проблема

Презентации часто готовят дома или скачивают из интернета. На школьном компьютере нестандартные шрифты «слетают», мелкий текст не читается с задних парт, объекты вылезают за край экрана, забытые автопереходы переключают слайды посреди объяснения, а невнедрённые видео и битые картинки не открываются. PowerPoint сам такие проблемы не ищет — программа проверяет всю презентацию (или целую папку с уроками) за секунду.

## Что проверяет программа (9 проверок)

| № | Проверка | Уровень | Что именно находит (с защитой от ложных срабатываний) |
|---|----------|---------|--------------------------------------------------------|
| 1 | Повреждённые медиафайлы | Критично | Битые картинки внутри архива `.pptx`, вместо которых на уроке будет пустая рамка |
| 2 | Перевёрнутые картинки | Внимание | Изображения «вверх ногами» (`flipV`), не трогая штатные зеркальные отражения `flipH` |
| 3 | Выход за границы слайда | Внимание | Видимые фигуры, таблицы и рисунки за краем листа (с учётом поворота и допуском 3 мм) |
| 4 | Перекрытие текста | Критично | Непрозрачные картинки, лежащие **поверх** текста (с учётом слоёв Z-order и прозрачности PNG) |
| 5 | Разрешение картинок | Внимание | Сильно растянутые картинки (`< 75 DPI` с учётом обрезки `crop`) — «пиксели» на проекторе |
| 6 | Нестандартные шрифты | Внимание | Шрифты вне стандартного набора Windows/Office, не внедрённые в файл (с расшифровкой тем `+mn-lt`) |
| 7 | Слишком мелкий кегль | Внимание | Текст мельче `14 пт`, который не прочитать с задних парт (кроме колонтитулов и номеров слайдов) |
| 8 | Автопереходы слайдов | Критично | Забытый таймер автопереключения (`advTm`) или заблокированный клик мыши |
| 9 | Внешние ссылки и файлы | Критично / Внимание | Локальные невнедрённые видео/файлы (`file://`, `C:\...`) и веб-ссылки (кроме `mailto:`) |

Также анализатор рекурсивно проверяет объекты внутри **групп (`Ctrl+G`)**, текст в **таблицах** и распознаёт старый формат **PowerPoint 97–2003 (`.ppt`)**, подсказывая, как пересохранить его в `.pptx`.

## Быстрый старт

```bash
# установка зависимостей (один раз)
pip install -r requirements.txt

# отчёт по одной презентации
python3 check_presentation.py презентация.pptx

# сводная таблица сразу по папке с презентациями
python3 check_presentation.py test_files/

# безопасно починить автопереходы и перевёрнутые картинки в КОПИЮ файла
python3 check_presentation.py презентация.pptx --fix

# самопроверка на эталоне + модульные тесты
python3 check_presentation.py --test
python3 -m unittest test_checker.py -v
```

### Графическое окно (`app_ui.py`)

```bash
python3 app_ui.py
```

В окне программы доступны:
- **«Выбрать .pptx…»** — мгновенная проверка презентации в фоновом потоке (без зависания окна);
- **«Проверить папку…»** — сводная таблица по всем презентациям в выбранной папке;
- **«Автоисправление (в копию)…»** — безопасное исправление перевёрнутых картинок и автопереходов без изменения оригинала;
- **Фильтр «Только критичные»** и **«Сохранить отчёт…»** в `.txt`.

Подробное руководство для учителя: [`ИНСТРУКЦИЯ.md`](ИНСТРУКЦИЯ.md).

### Windows 10 / 11

```bat
py -3 -m pip install -r requirements.txt
py -3 app_ui.py
```

### Готовые сборки (Releases — без установки Python)

На странице **Releases** репозитория автоматически собираются готовые приложения:

| Система | Файл | Как запускать |
|---------|------|---------------|
| Windows 10/11 | `pptx-checker-windows.exe` | Двойной клик — сразу открывается окно (без консоли) |
| Linux | `pptx-checker-linux` | `chmod +x pptx-checker-linux && ./pptx-checker-linux` |

Можно передать путь к презентации аргументом (`pptx-checker-windows.exe урок.pptx`) — окно откроется и сразу покажет отчёт.

## Структура репозитория

```text
check_presentation.py         # ядро анализа (9 проверок, пакетный режим, --fix, --test)
app_ui.py                     # графический интерфейс на tkinter / ttk
launcher.py                   # точка входа для exe / Linux-сборки
generate_test_files.py        # генератор эталонных презентаций broken.pptx и clean.pptx
test_checker.py               # модульные и регрессионные тесты (unittest)
ИНСТРУКЦИЯ.md                 # краткая памятка для учителя
requirements.txt              # зависимости (python-pptx, Pillow)
.github/workflows/ci.yml      # автотесты на Ubuntu и Windows при каждом push
.github/workflows/release.yml # сборка готовых приложений по тегу v*
test_files/                   # эталонные и реальные учебные презентации
```

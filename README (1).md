# 📊 Проверка презентации .pptx перед уроком

Программа на Python проверяет учебную презентацию по **7 параметрам** и выдаёт отчёт: на каком слайде какая ошибка — **до того**, как файл покажут на уроке.

> Учебный проект для проектной деятельности, 10 класс. Работаю один.

## Проблема

Презентации часто переносят на другой компьютер или скачивают из интернета. На компьютере в классе шрифты «слетают», текст вылезает за слайд, картинки переворачиваются — PowerPoint сам такие проблемы не ищет, их приходится искать глазами прямо перед уроком.

## Что проверяет (7 проверок)

| № | Проверка | Что находит |
|---|----------|-------------|
| 1 | Перевёрнутые картинки | flipV / flipH — «вверх ногами» |
| 2 | Границы слайда | объекты вылезают за край |
| 3 | Перекрытие | картинка накрывает текст |
| 4 | Шрифты | нестандартные шрифты «слетают» на другом ПК |
| 5 | Разрешение картинок | < 150 DPI — на проекторе пиксели |
| 6 | Внешние ссылки | ссылки, которые не откроются в классе |
| 7 | Автопереходы | слайды уплывают сами во время объяснения |

## Быстрый старт

```bash
# установка (один раз)
pip install python-pptx

# отчёт по презентации
python3 check_presentation.py презентация.pptx

# починить безопасное в КОПИЮ (исходник не трогается)
python3 check_presentation.py презентация.pptx --fix

# самопроверка программы на эталонных файлах
python3 check_presentation.py --test
```

### Windows 10

1. Скачай Python с [python.org](https://www.python.org/downloads/) — при установке поставь галочку **Add python.exe to PATH**
2. Открой командную строку (`Win+R` → `cmd`) в папке репозитория и выполни:

```bat
py -3 -m pip install -r requirements.txt
py -3 check_presentation.py --test
py -3 check_presentation.py презентация.pptx
```

Окно интерфейса: `py -3 app_ui.py` (tkinter встроен в Python для Windows — отдельно ставить не нужно).

### WSL2 (Ubuntu)

```bash
sudo apt update && sudo apt install -y python3-pip python3-tk
pip install -r requirements.txt
python3 check_presentation.py --test        # самопроверка
python3 app_ui.py                           # окно (нужен python3-tk)
```

Пакет `python3-tk` нужен только для окна `app_ui.py`; сам проверяльщик работает и без него.

### Автопроверка в GitHub Actions

При каждом push репозиторий сам проверяется на **Ubuntu и Windows**: установка зависимостей → компиляция файлов → генерация эталонов → самопроверка `--test` → прогон на реальной презентации. Workflow: `.github/workflows/ci.yml`.

## Готовые сборки (Releases)

Не хочешь ставить Python? На странице **Releases** репозитория лежат готовые программы — скачиваешь и запускаешь:

| Система | Файл |
|---------|------|
| Windows 10/11 | `pptx-checker-windows.exe` |
| Linux | `pptx-checker-linux` |

```bat
:: Windows: открой cmd в папке загрузок
pptx-checker-windows.exe презентация.pptx
```

**Двойной клик без аргументов** — откроется окно интерфейса с кнопками «Обзор» и «Проверить»: выбери файл, нажми «Проверить», сохрани отчёт. Без интерфейса программа работает только когда задан файл или флаг `--test` из командной строки.

```bash
# Linux
chmod +x pptx-checker-linux
./pptx-checker-linux презентация.pptx
```

Windows может написать «неизвестный издатель» — нажми «Подробнее» → «Всё равно запустить». Это нормально: у проекта нет коммерческого сертификата.

Сборка автоматическая: выставлен тег `v*` → GitHub Actions соберёт файлы и создаст страницу Releases (workflow: `.github/workflows/release.yml`).

## Структура репозитория

```
check_presentation.py     # основная программа (7 проверок, --fix, --test)
app_ui.py                 # окно интерфейса на tkinter (в разработке)
generate_test_files.py    # генератор тестовых презентаций с дефектами
requirements.txt          # зависимости (python-pptx)
.github/workflows/ci.yml  # автопроверка на Ubuntu и Windows при каждом push
.github/workflows/release.yml # сборка готовых программ (Releases) по тегу
.gitignore                # что не коммитить
test_files/               # эталонные файлы: broken.pptx, clean.pptx, ...
```

Автогенерируются командой `python3 generate_test_files.py` (в репозитории уже лежат).
